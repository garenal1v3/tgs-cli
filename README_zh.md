## 特性

- 搜索消息、聊天、频道——Telegram API 提供的一切
- 通过您的真实 Telegram 账户运行，而非机器人
- 默认 JSON 输出——专为脚本和 AI 代理设计
- 多账户配置，类似 AWS CLI
- 单一二进制文件，零依赖——随处运行
- 瓶颈在于 Telegram API，而非应用本身
