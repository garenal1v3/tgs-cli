# 搜索命令

用于在 Telegram 聊天、频道和群组中搜索消息的命令。

- [tgs search messages]({{< relref "/reference/commands/search/messages" >}}) — 在指定聊天中搜索
- [tgs search global]({{< relref "/reference/commands/search/global" >}}) — 跨所有聊天的全局搜索
- [tgs search counters]({{< relref "/reference/commands/search/counters" >}}) — 按内容类型分组的消息计数
- [tgs search calendar]({{< relref "/reference/commands/search/calendar" >}}) — 按日期分组的搜索结果
