# Команды аккаунта

Команды для управления профилями и просмотра текущей сессии.

- [tgs profile]({{< relref "/reference/commands/account/profile" >}}) — список, переключение и удаление профилей
- [tgs whoami]({{< relref "/reference/commands/account/whoami" >}}) — текущий профиль и аутентифицированный пользователь
