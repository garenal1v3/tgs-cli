# Команды поиска

Команды для поиска сообщений в чатах, каналах и группах Telegram.

- [tgs search messages]({{< relref "/reference/commands/search/messages" >}}) — поиск в конкретных чатах
- [tgs search global]({{< relref "/reference/commands/search/global" >}}) — глобальный поиск по всем чатам
- [tgs search counters]({{< relref "/reference/commands/search/counters" >}}) — счётчики сообщений по типам контента
- [tgs search calendar]({{< relref "/reference/commands/search/calendar" >}}) — результаты поиска, сгруппированные по дате
