# Команды аутентификации

Команды для управления Telegram-сессией: вход и выход.

- [tgs login]({{< relref "/reference/commands/auth/login" >}}) — авторизация в Telegram (импорт Desktop, телефон+код или QR)
- [tgs logout]({{< relref "/reference/commands/auth/logout" >}}) — очистка сессии и удаление кэшированных данных
