# Команды sources

Команды для перечисления и изучения диалогов Telegram (каналы, группы, пользователи, боты) в вашем аккаунте.

- [tgs sources list]({{< relref "/reference/commands/sources/list" >}}) — список всех диалогов с опциональной статистикой
- [tgs sources inspect]({{< relref "/reference/commands/sources/inspect" >}}) — подробная информация об одном источнике
