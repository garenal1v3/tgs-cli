# tgs sources folders

Перечисляет **папки** Telegram пользователя (диалоговые фильтры из интерфейса) и
раскрывает содержимое каждой из них так, как это делает клиент Telegram — применяя
закреплённые / включённые / исключённые пиры и автоматические правила (контакты, группы и т.д.)
к полному списку диалогов.

Папка «Все чаты» по умолчанию исключается из вывода; отображаются только
пользовательские папки и чат-листы.

### Поля папки

| Поле | Тип | Описание |
|---|---|---|
| `id` | int | ID диалогового фильтра в Telegram |
| `kind` | string | `custom` — пользовательская папка; `chatlist` — чат-лист |
| `title` | string | Отображаемое название папки |
| `emoticon` | string | Эмодзи папки; отсутствует, если не задано |
| `has_my_invites` | bool | В чат-листе есть ссылки-приглашения, созданные вами; присутствует только если `true` |
| `chats_count` | int | Количество чатов в массиве `chats` |
| `chats` | array | Разрешённые записи чатов (та же структура, что и источники в `sources list`) |
| `total` | int | Общее количество возвращённых папок |

Записи чатов внутри `chats` имеют ту же структуру полей, что и источники в
[tgs sources list]({{< relref "/reference/commands/sources/list" >}}).

## Примечания

- Если папка явно включает архивные чаты (например, через `include_peers`),
  но флаг `--archived` не передан, эти архивные чаты не появятся в выводе —
  команда не обходила архивную папку. Передайте `--archived` для полной картины.
- Содержимое папок не разбивается на страницы. Общее число папок невелико
  (Telegram ограничивает ~30), и чаты каждой папки возвращаются в одном ответе.
