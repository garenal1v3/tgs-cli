# tgs logout

Отзывает текущую сессию на серверах Telegram и удаляет локальные данные сессии.

## Использование

```
tgs logout [flags]
```

## Флаги

| Флаг | Краткий | По умолчанию | Описание |
|------|---------|--------------|----------|
| `--profile` | `-p` | (определяется автоматически) | Профиль для выхода |

## Примеры

```bash
tgs logout
tgs logout --profile work
```
