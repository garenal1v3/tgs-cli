# Переменные окружения

| Переменная | Описание |
|------------|----------|
| `TGS_PROFILE` | Переопределяет имя активного профиля |
| `TGS_API_ID` | Переопределяет Telegram API ID |
| `TGS_API_HASH` | Переопределяет Telegram API Hash |
| `TGS_CONFIG_DIR` | Переопределяет директорию конфигурации (по умолчанию: `~/.config/tgs`) |
| `TGS_DATA_DIR` | Переопределяет директорию данных (по умолчанию: `~/.local/share/tgs`) |
