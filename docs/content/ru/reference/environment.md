## API-ключи

tgs поставляется с вкомпилированными API-ключами. Большинству пользователей не нужно их менять. Переопределение может понадобиться, если вы собираете tgs из исходников без ключей или хотите использовать свои учётные данные приложения Telegram.

{{< snippet "env/api-usage.md" >}}

Получить API-ключи можно на [my.telegram.org](https://my.telegram.org).
