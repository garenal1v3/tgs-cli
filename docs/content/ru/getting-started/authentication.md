# Аутентификация

tgs подключается к Telegram через ваш реальный аккаунт по протоколу MTProto. Аутентификация нужна один раз для каждого профиля — сессия сохраняется локально и используется повторно при последующих командах.

## Методы входа

### Импорт из Desktop (по умолчанию)

Импортирует существующую сессию из Telegram Desktop. tgs автоматически определяет директорию tdata на macOS, Linux и Windows.

{{< snippet "auth/desktop.md" >}}

Ввод номера телефона или кода не требуется — сессия передаётся напрямую.

### Телефон + код

Интерактивный вход с номером телефона. Поддерживает двухфакторную аутентификацию (облачный пароль).

{{< snippet "auth/code-login.md" >}}

tgs запросит код подтверждения, отправленный Telegram. Если включена 2FA, также будет запрошен облачный пароль.

### Неинтерактивный вход (для AI-агентов)

Метод `code` поддерживает полностью неинтерактивный двухшаговый вход. Это рекомендуемый способ для AI-агентов и средств автоматизации.

{{< snippet "auth/code-noninteractive.md" >}}

### QR-код

Отображает QR-код в терминале. Отсканируйте его в приложении Telegram на другом устройстве.

{{< snippet "auth/qr-login.md" >}}

После сканирования tgs автоматически завершает аутентификацию. Если включена 2FA, будет запрошен облачный пароль.
