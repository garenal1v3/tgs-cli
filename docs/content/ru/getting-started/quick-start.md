# Быстрый старт

От нуля до первого поиска за пять команд. Предполагается, что tgs уже установлен — если нет, смотрите [Установку]({{< relref "/getting-started/installation" >}}).

## 1. Аутентификация

Вход по умолчанию импортирует существующую сессию из Telegram Desktop — без номера телефона и кода:

{{< snippet "auth/quick-start.md" >}}

Другие методы (телефон + код, QR, неинтерактивный вход для AI-агентов) описаны в разделе [Аутентификация]({{< relref "/getting-started/authentication" >}}).

## 2. Проверка аккаунта

{{< snippet "auth/verify.md" >}}

Возвращает активный аккаунт в JSON — ваш ID, имя и username.

## 3. Список ваших чатов

Посмотрите все диалоги в аккаунте — каналы, группы, пользователей, ботов:

{{< snippet "quick-start/sources.md" >}}

Добавьте `--type channel` для фильтрации по типу или `--with-stats` для подсчёта сообщений. Подробнее — в разделе [Источники]({{< relref "/guide/sources" >}}).

## 4. Поиск внутри чата

{{< snippet "quick-start/search-chat.md" >}}

`-c` принимает username, ссылку `t.me`, номер телефона или числовой ID. Сужайте выдачу флагами `--from`, `--filter` и `--after` / `--before`.
