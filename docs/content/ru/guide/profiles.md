# Профили

tgs поддерживает несколько аккаунтов Telegram через профили — по аналогии с профилями AWS CLI.

## Порядок определения профиля

tgs определяет активный профиль по следующему приоритету (от высшего к низшему):

1. Флаг `--profile`
2. Переменная окружения `TGS_PROFILE`
3. Файл `.tgs.yaml` в текущей или родительской директории
4. `"default"`

## Профили для отдельных директорий

Создайте файл `.tgs.yaml`, чтобы привязать профиль к директории:

```bash
tgs profile switch work
```

Команда записывает `.tgs.yaml` в текущую директорию:

```yaml
profile: work
```

tgs ищет `.tgs.yaml`, поднимаясь по дереву директорий, поэтому привязка работает и во вложенных папках.

## Управление профилями

### Список профилей

```bash
tgs profile list
```

Пример вывода:
```
* default (+71234567890, @myuser)
  work (+70987654321, @workuser)
```

### Переключить профиль

```bash
tgs profile switch work
```

### Удалить профиль

```bash
tgs profile delete old-account
```

Нельзя удалить активный профиль.

### Узнать текущий профиль

```bash
tgs whoami
```

Пример вывода:
```
Profile: work
User:    Иван Иванов
Handle:  @ivanov
Phone:   +71234567890
ID:      123456789
```

## Переменная окружения

Установите `TGS_PROFILE`, чтобы переопределить профиль для одной команды или всей сессии:

```bash
TGS_PROFILE=work tgs whoami
export TGS_PROFILE=work  # для всей сессии оболочки
```
