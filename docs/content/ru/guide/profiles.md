# Профили

tgs поддерживает несколько аккаунтов Telegram через профили — по аналогии с профилями AWS CLI. У каждого профиля своя независимая сессия, хранящаяся в отдельном файле базы данных.

## Порядок определения профиля

При запуске любой команды tgs активный профиль определяется по следующему приоритету (от высшего к низшему):

1. Флаг `--profile`, переданный команде
2. Переменная окружения `TGS_PROFILE`
3. Файл `.tgs.yaml` в текущей или родительской директории
4. `"default"` (значение по умолчанию)

## Профили для отдельных директорий

Вы можете привязать профиль к директории, создав файл `.tgs.yaml`. Используйте `tgs profile switch` для автоматического создания:

{{< snippet "profiles/switch-yaml.md" >}}

tgs ищет `.tgs.yaml`, поднимаясь по дереву директорий, поэтому привязка работает и во вложенных папках. Это рекомендуемый способ использования разных аккаунтов для разных проектов.
