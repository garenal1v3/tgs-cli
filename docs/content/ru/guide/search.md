# Поиск

> **Примечание:** Эта документация может отставать от [английской версии](/en/guide/search/).

tgs предоставляет четыре подкоманды для поиска: `messages`, `global`, `counters` и `calendar`. Все они возвращают JSON и поддерживают пагинацию, что делает их удобными как для людей, так и для AI-агентов.

## Поиск в чате

Основная команда -- `tgs search messages`. Она ищет сообщения в одном или нескольких указанных чатах.

```bash
tgs search messages "запрос" -c @channel
```

Аргумент `"запрос"` -- текст для поиска. Флаг `-c` (или `--chat`) указывает чат, в котором нужно искать. Этот флаг обязателен.

Пример -- найти упоминания "релиз" в канале:

```bash
tgs search messages "релиз" -c @golang_news
```

## Несколько чатов

Можно искать сразу в нескольких чатах. Передайте их через запятую или повторите флаг `-c`:

```bash
# Через запятую
tgs search messages "баг" -c @channel1,@channel2,@channel3

# Через повторение флага
tgs search messages "баг" -c @channel1 -c @channel2
```

При поиске по нескольким чатам результаты объединяются и сортируются по дате (от новых к старым). Пагинация автоматически отслеживает состояние для каждого чата.

## Фильтр по автору

Используйте `--from` (или `-f`), чтобы показать только сообщения конкретного пользователя:

```bash
tgs search messages "вопрос" -c @group --from @username
tgs search messages "" -c @group -f 123456789
```

Значением `--from` может быть юзернейм, числовой ID пользователя или телефон. Пустой запрос `""` в сочетании с `--from` вернет все сообщения от указанного автора.

## Фильтр по типу контента

Флаг `--filter` ограничивает результаты определенным типом медиа. Поддерживаются 15 фильтров:

| Фильтр | Описание |
|---|---|
| `photo` | Фотографии |
| `video` | Видео |
| `photo-video` | Фото и видео вместе |
| `document` | Документы (файлы) |
| `url` | Сообщения со ссылками |
| `gif` | GIF-анимации |
| `voice` | Голосовые сообщения |
| `music` | Аудиофайлы (музыка) |
| `round-video` | Видеосообщения (кружочки) |
| `geo` | Геолокации |
| `contact` | Контакты |
| `pinned` | Закрепленные сообщения |
| `mention` | Упоминания вас |
| `phone-call` | Звонки |
| `chat-photo` | Фото чата (аватарки) |

Примеры:

```bash
# Найти все фотографии в канале
tgs search messages "" -c @channel --filter photo

# Найти документы с ключевым словом
tgs search messages "отчет" -c @work_chat --filter document

# Голосовые сообщения от конкретного пользователя
tgs search messages "" -c @group --filter voice --from @user
```

## Фильтр по дате

Флаги `--after` и `--before` ограничивают результаты по дате. Принимают формат `YYYY-MM-DD` или Unix-timestamp:

```bash
# Сообщения после 1 января 2025
tgs search messages "итоги" -c @channel --after 2025-01-01

# Сообщения за декабрь 2024
tgs search messages "" -c @channel --after 2024-12-01 --before 2025-01-01

# С использованием Unix-timestamp
tgs search messages "событие" -c @channel --after 1704067200
```

`--after` и `--before` можно комбинировать с любыми другими фильтрами.

## Темы форума

Для поиска в конкретной теме (topic) форума используйте `--topic` с ID темы:

```bash
tgs search messages "вопрос" -c @forum_group --topic 42
```

ID темы -- это числовой идентификатор топика в форуме. Флаг `--topic` работает только для супергрупп с включенными форумами.

## Глобальный поиск

`tgs search global` ищет сообщения по всем вашим чатам одновременно -- без необходимости указывать конкретный чат:

```bash
tgs search global "ключевое слово"
```

### Фильтрация по типу чата

Ограничьте поиск определенным типом чатов:

```bash
# Только каналы
tgs search global "новости" --channels-only

# Только группы
tgs search global "обсуждение" --groups-only

# Только личные сообщения
tgs search global "привет" --users-only
```

### Поиск в папке

Ограничьте поиск конкретной папкой Telegram по её ID:

```bash
tgs search global "задача" --folder 3
```

### Дополнительные фильтры

Глобальный поиск также поддерживает `--filter`, `--after`, `--before` -- аналогично поиску в чате:

```bash
tgs search global "презентация" --filter document --after 2025-01-01
```

## Счетчики контента

`tgs search counters` показывает количество сообщений каждого типа в чате:

```bash
tgs search counters -c @channel
```

Пример ответа:

```json
{
  "counters": [
    {"filter": "photo", "count": 1523},
    {"filter": "video", "count": 342},
    {"filter": "document", "count": 89},
    {"filter": "url", "count": 4210}
  ]
}
```

По умолчанию возвращаются счетчики для всех 15 типов фильтров. Чтобы запросить только определенные типы, используйте `--filters`:

```bash
tgs search counters -c @channel --filters photo,video,document
```

Счетчики также поддерживают `--topic` для форумов:

```bash
tgs search counters -c @forum_group --topic 42
```

## Календарное представление

`tgs search calendar` группирует результаты поиска по дате. Требует указания чата и фильтра:

```bash
tgs search calendar -c @channel --filter photo
```

Пример ответа:

```json
{
  "periods": [
    {"date": "2025-05-20", "count": 12, "min_msg_id": 4501, "max_msg_id": 4530},
    {"date": "2025-05-19", "count": 8, "min_msg_id": 4480, "max_msg_id": 4499},
    {"date": "2025-05-15", "count": 3, "min_msg_id": 4450, "max_msg_id": 4455}
  ],
  "total": 23
}
```

Каждый период содержит дату, количество сообщений и диапазон ID сообщений. Это полезно для визуализации активности или навигации по архиву.

## Курсорная пагинация

Все поисковые команды возвращают до 100 результатов за запрос (по умолчанию 50, настраивается через `--limit`). Если результатов больше, в ответе будет поле `cursor`:

```json
{
  "messages": [...],
  "total": 1520,
  "cursor": "eyJvIjo0NTAsImQiOjB9"
}
```

Передайте значение `cursor` в следующий запрос, чтобы получить следующую страницу:

```bash
# Первая страница
tgs search messages "тема" -c @channel --limit 20

# Следующая страница
tgs search messages "тема" -c @channel --limit 20 --cursor "eyJvIjo0NTAsImQiOjB9"
```

Когда результатов больше нет, поле `cursor` отсутствует в ответе. При поиске по нескольким чатам пагинация автоматически отслеживает прогресс по каждому чату.

## Резолв чатов

Флаг `-c` / `--chat` и `--from` принимают идентификаторы чатов и пользователей в различных форматах:

| Формат | Пример | Тип |
|---|---|---|
| `@username` | `@durov` | Юзернейм |
| `username` | `durov` | Юзернейм (без @) |
| Числовой ID | `123456789` | ID пользователя/чата |
| Отрицательный ID | `-1001234567890` | ID супергруппы/канала |
| Телефон | `+79001234567` | Номер телефона (7+ цифр) |
| Ссылка t.me | `t.me/durov` | Ссылка на профиль |
| Полная ссылка | `https://t.me/durov` | Ссылка с протоколом |
| telegram.me | `telegram.me/durov` | Альтернативный домен |

> **Примечание:** Инвайт-ссылки (`t.me/+hash`) не поддерживаются для поиска.

Разрешенные пиры кешируются локально для ускорения повторных запросов. Чтобы отключить кеш, используйте `--no-cache`.

## Обработка лимитов

Telegram ограничивает частоту API-запросов. При превышении лимита сервер возвращает ошибку `FLOOD_WAIT_N`, где N -- количество секунд ожидания.

tgs обрабатывает это автоматически:

- Если время ожидания не превышает `--max-wait` (по умолчанию 60 секунд), tgs ждет и повторяет запрос
- Если время ожидания больше `--max-wait`, возвращается ошибка
- Для транзитных ошибок применяется экспоненциальный backoff с jitter (до 3 попыток)

```bash
# Увеличить допустимое время ожидания до 120 секунд
tgs search messages "запрос" -c @channel --max-wait 120

# Уменьшить для быстрого отказа
tgs search messages "запрос" -c @channel --max-wait 10
```

Информация об ожидании выводится в stderr, чтобы не нарушать JSON-вывод в stdout.
