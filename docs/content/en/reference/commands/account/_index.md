# Account Commands

Commands for managing account profiles and inspecting the active session.

- [tgs profile]({{< relref "/reference/commands/account/profile" >}}) — list, switch between, or delete profiles
- [tgs whoami]({{< relref "/reference/commands/account/whoami" >}}) — show the active profile and authenticated user
