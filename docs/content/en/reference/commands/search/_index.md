# Search Commands

Commands for searching messages across Telegram chats, channels, and groups.

- [tgs search messages]({{< relref "/reference/commands/search/messages" >}}) — search within specific chats
- [tgs search global]({{< relref "/reference/commands/search/global" >}}) — search across all chats at once
- [tgs search counters]({{< relref "/reference/commands/search/counters" >}}) — message counts grouped by content type
- [tgs search calendar]({{< relref "/reference/commands/search/calendar" >}}) — search results grouped by date
