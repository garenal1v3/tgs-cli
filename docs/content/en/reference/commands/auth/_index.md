# Authentication Commands

Commands for managing Telegram session: signing in and signing out.

- [tgs login]({{< relref "/reference/commands/auth/login" >}}) — authenticate with Telegram (Desktop import, phone+code, or QR)
- [tgs logout]({{< relref "/reference/commands/auth/logout" >}}) — clear the session and remove cached data
