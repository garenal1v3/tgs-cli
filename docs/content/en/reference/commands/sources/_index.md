# Sources Commands

Commands for enumerating and inspecting Telegram dialogs (channels, groups, users, bots) in your account.

- [tgs sources list]({{< relref "/reference/commands/sources/list" >}}) — enumerate all dialogs with optional stats
- [tgs sources inspect]({{< relref "/reference/commands/sources/inspect" >}}) — detailed info for a single source
