## Возможности

- Поиск сообщений, чатов, каналов — всё, что даёт Telegram API
- Работает через ваш аккаунт Telegram, не через бота
- JSON по умолчанию — создан для скриптов и AI-агентов
- Несколько профилей аккаунтов, как в AWS CLI
- Один бинарник, ноль зависимостей — работает где угодно
- Узкое место — Telegram API, не приложение
